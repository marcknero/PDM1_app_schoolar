# Scholar

Aplicativo escolar reestruturado com React Navigation, telas em `src/` e identidade visual azul-esverdeada.

## Estrutura

- `src/components`: componentes reutilizáveis da interface
- `src/contexts`: contexto de autenticação
- `src/navigation`: stack de login e tabs principais
- `src/screens`: telas de login, início, cadastros e boletim
- `src/services`: dados e integrações simuladas
- `src/styles`: tema e estilos centralizados

## Telas iniciais

- Login
- Início
- Cadastro de alunos
- Cadastro de professores
- Cadastro de disciplinas
- Visualização de boletim

## Executar

```bash
npm install
npx expo start
```

# Dados Temporários e Mokados
A aplicação, em sua versão atual, nao apresente plena funcionalidade e ainda não está realizando a permanencia dos dados, ou validações de cadastramento ou afins.
Ele apresenta de forma pratica e com dados generalizados e ficticios, o conjunto de telas e componentes inicialmente planejados para o projeto.
Versão mais completas a serem atualizadas junto a exclusão deste esclarecimento.
